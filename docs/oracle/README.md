# Oracle 호환

xqlite의 Oracle Database 방언이 제공하는 문법, 동작 방식, 사용 방법 및 호환성 가이드입니다. Oracle Database 23ai 표준을 기준으로 설계되었으며 SQLite 임베디드 코어 위에서 동작합니다.

---

## 1. 켜는 법 (사용 방법)

| 환경 | 활성화 방법 | 설명 |
| --- | --- | --- |
| **SQL 질의** | `PRAGMA xq_dialect = 'oracle';` | 세션의 현재 방언을 Oracle로 변경합니다. 언제든 `PRAGMA xq_dialect = 'sqlite';`로 돌아올 수 있습니다. |
| **xqlite CLI 셸** | `.dialect oracle` | 인터랙티브 셸 프롬프트에서 방언을 전환합니다. |
| **Zig API** | `db.setDialect(.oracle);` | 애플리케이션 임베딩 시 연결 단위로 방언을 설정합니다. |

---

## 2. 빠른 시작 (Quickstart)

```sql
-- Oracle 방언 활성화
PRAGMA xq_dialect = 'oracle';

-- 테이블 생성 (Oracle 전용 타입 NUMBER, VARCHAR2, DATE, IDENTITY 지원)
CREATE TABLE emp (
  empno    NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  ename    VARCHAR2(50) NOT NULL,
  sal      NUMBER(8,2),
  comm     NUMBER(8,2),
  hiredate DATE DEFAULT SYSDATE
);

-- DML 실행 시 암묵적으로 트랜잭션이 시작됩니다.
INSERT INTO emp (ename, sal, comm) VALUES ('KING', 5000, NULL);
INSERT INTO emp (ename, sal, comm) VALUES ('BLAKE', 2850, 0);

-- Oracle에서는 DML 변경사항을 영구 반영하려면 명시적으로 COMMIT 해야 합니다.
COMMIT;

-- Oracle 특유의 DUAL 가상 테이블, ROWNUM, NVL, TO_CHAR 질의
SELECT ename,
       sal + NVL(comm, 0) AS total_pay,
       TO_CHAR(hiredate, 'YYYY-MM-DD') AS hired
FROM emp
WHERE ROWNUM <= 10
ORDER BY sal DESC;

-- 빈 문자열은 Oracle 규칙에 따라 NULL로 처리됩니다.
SELECT CASE WHEN '' IS NULL THEN 'Empty string is NULL' ELSE 'Not NULL' END AS result
FROM DUAL;

-- SQLite 방언으로 복귀
PRAGMA xq_dialect = 'sqlite';
```

## 3. 핵심 기능 요약

- **Oracle 고유 시맨틱**:
  - **대문자 식별자 폴딩**: 인용부호 없는 테이블/열 이름은 자동으로 대문자로 변환됩니다.
  - **빈 문자열의 NULL 취급**: `''` 리터럴, 빈 문자열 결합, 함수 반환값은 모두 `NULL`로 평가됩니다.
  - **암묵적 트랜잭션**: `BEGIN` 문장 없이 첫 번째 DML 실행 시 트랜잭션이 자동 개방되며 `COMMIT` 또는 `ROLLBACK`으로 종료합니다.
  - **`DUAL` 테이블 및 `ROWNUM` 가상 열** 완벽 지원.
- **Oracle 데이터 타입**: `NUMBER(p,s)`, `VARCHAR2(n)`, `CHAR(n)`, `DATE` (시간 포함), `TIMESTAMP`, `CLOB`, `BLOB`, `RAW(n)` 지원.
- **고급 DML**: `MERGE INTO`, `INSERT ALL`, `(+)` 외부 조인 구문 지원.
- **풍부한 내장 함수**: `NVL`, `NVL2`, `DECODE`, `TO_CHAR`, `TO_DATE`, `ADD_MONTHS`, `MONTHS_BETWEEN`, `SYS_CONTEXT`, `JSON_OBJECT`, `JSON_ARRAY` 지원.
- **데이터 사전 뷰**: `USER_TABLES`, `USER_TAB_COLUMNS`, `ALL_TABLES` 등 핵심 카탈로그 가상 뷰 지원.
