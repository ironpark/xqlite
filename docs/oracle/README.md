## 켜는 법

| 어디서 | 방법 |
| --- | --- |
| SQL | `PRAGMA xq_dialect = 'oracle'` |
| 셸 | `.dialect oracle` |
| Zig API | `.dialect = .oracle` |

```sql
PRAGMA xq_dialect = 'oracle';
CREATE TABLE emp (
  id     NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name   VARCHAR2(40) NOT NULL,
  salary NUMBER(8,2),
  hired  DATE DEFAULT SYSDATE
);
INSERT INTO emp (name, salary) VALUES ('ann', 1000);
COMMIT;                                   -- DML은 트랜잭션을 엽니다
SELECT name, TO_CHAR(hired, 'YYYY-MM-DD') FROM emp WHERE ROWNUM <= 10;
SELECT column_name, data_type FROM user_tab_columns WHERE table_name = 'EMP';
PRAGMA xq_dialect = 'sqlite';             -- PRAGMA는 SQLite 문법 그대로 통과
```
